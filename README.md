# Super Store Sales Analysis Project

## Project Objective

The main objective of this project is to analyze Super Store sales performance and identify business trends that improve profitability, customer engagement, and operational efficiency. The analysis focuses on understanding sales distribution, profit contribution, customer segments, regional performance, product categories, and payment behavior to support data-driven business decisions.
